# UI audit

The pre-rebuild interface had the prototype signals identified in the design brief:

- Navigation was a top bar rather than a calm, persistent workspace shell.
- The native document scope select and bordered search form made the primary interaction feel
  like a form.
- Answers, evidence, metrics, and settings were all presented as bordered cards with similar
  visual weight.
- Answer copy exposed report-speak labels and raw bracketed citations.
- Evidence was presented as a large grid of raw snippets instead of a small source row with a
  drawer for inspection.
- The typography and spacing used many ad-hoc values and did not distinguish reading text from UI.
- Loading, empty, and error states existed, but did not share a consistent conversational pattern.

This audit is a baseline for the rebuild; it is not a claim that the backend retrieval behavior
changed.
