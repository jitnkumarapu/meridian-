# Gold-set human review

Before setting `verified: true`, a reviewer must open the cited page and confirm: the question is
unambiguous without future knowledge; the reference answer and units are exact; every supporting
chunk/page/modality is included; no answer text leaks into the question; and the type label is one of
text, table, figure, or multimodal. Figure questions must be answerable from the static visual or its
caption/OCR without reconstructing hidden chart data. Record reviewer name, date, and correction.

Use at least 60 questions across the 15-report corpus, balanced by type. Report the verified subset
separately and never present unverified drafts as benchmark truth.
